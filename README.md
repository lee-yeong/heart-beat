# 교양필수 ♥

> "우리 사이엔 무슨 일이 생길까?"
> AI가 수강생을 분석해 다른 전공 학생과 이어주는 대학 생활 웹 (인천대학교 기준)
> 바이브코딩 대회 출품작 · 주제 "AI로 다시 쓰는 대학생활"
>
> **배포 주소: https://heart-beat-sigma-two.vercel.app** (휴대폰 브라우저로 접속)

## 문제

1학년 때는 과대가 과팅을 잡아주지만, 2학년부터는 지인을 통하지 않으면 다른 과 사람을 만날 계기가 없어요.

## 사용 흐름

1. **학적 등록:** 아이디·비밀번호를 만들고, 전공과 '전공 밖의 나'(특징 키워드, 음악 취향)를 버튼으로 고른다.
2. **AI 학사 분석:** AI가 전공과 성향의 조합을 해석해 학생증에 보여준다.
3. **AI 추천 수강 목록:** AI가 다른 전공 학생 3명과 추천 근거(전공 시너지, 성향 보완, 실제 공통점, 첫 대화 주제)를 보여준다.
4. **수강신청:** AI가 추천한 첫 인사 3개 중 하나를 고르거나 직접 써서 친구 요청을 보낸다.
5. **수강 승인 → 강의실:** 상대가 승인하면 채팅이 열린다. 읽음 표시 "1"이 있다.
6. **우리의 강의계획서:** 2026-2학기 실제 개설 교양 중 두 사람에게 맞는 과목을 AI가 골라 3주 계획, 대화 과제, 첫 만남 제안으로 재해석한다.
7. **3일 수강 기간:** 처음 3일은 실명·나이·연락처 공유를 막는다. 둘 다 '계속 수강하기'를 누르면 연락처를 교환할 수 있다.
8. **수강 철회 → 재매칭:** 관계가 끝나면 AI 조교가 "매칭을 다시 시작할까요?"라고 묻고, 동의하면 새로 추천한다.
9. **AI 매칭 상담:** "추천해준 사람이 안 맞아요"라고 말하면 AI가 원하는 친구 상을 정리해 다시 추천한다.

## AI가 하는 일

| 기능 | 코드가 하는 일 | AI (Claude) | 서버 검증과 대체 |
|---|---|---|---|
| 학사 분석 | 입력 정리 | 전공×성향 해석 | 스키마 검증 → 1회 재시도 → 기본 분석 |
| 매칭 | 본인·같은 과·관계 있는 사람 제외, 최대 20명 | 3명과 근거 선정 | 후보 ID 실존, 근거 키워드가 두 프로필에 실제로 있는지 검사 → 실패 사유를 알려주고 재시도 → 규칙 기반 추천 |
| 수강신청 한마디 | 추천 근거 전달 | 첫 인사 3개 | 개수·길이 검사, 연락처 포함 시 전송 거부 |
| 강의계획서 | 두 사람에게 맞는 과목 후보 20개 (온라인 제외) | 1개 선택 + 재해석 | 과목 ID 검증, 만남 장소 = "○호관 1층 입구", 날짜 지정 금지. 과목명·교수·시간·장소는 편람 원본 그대로 |
| 대화 주제 | 최근 대화 20개 | 질문 3개 | 버튼을 누를 때만, 5초 간격 제한, 자동 전송 없음 |
| 매칭 상담 | 대화 기록 | 공감 답변 + 선호 정리 | 선호는 본인에게만 저장, 추천 프롬프트에 데이터로만 반영 |

- 사용자 입력은 `<profile_data>` 태그로 감싸 데이터로만 다룬다. 그 안의 지시문은 따르지 않는다.
- MBTI·혈액형은 판단 근거로 쓰지 않고, 궁합 점수도 보여주지 않는다.

## 기술 스택

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS 4 · Supabase (Postgres) · Anthropic Claude API (`claude-sonnet-5-5`, 구조화 출력) · Vercel

- **모바일 우선 웹:** PC에서는 인스타그램 PC처럼 바뀐다. 왼쪽 접히는 메뉴, 가운데 피드, 오른쪽 활동 열, 오른쪽 아래 작은 메시지 창.
- **DB 접근:** 클라이언트는 Supabase에 직접 접근하지 않고 Next.js API만 호출한다. 모든 테이블에 RLS를 켰고 service_role만 권한이 있다.
- **수강신청 규칙은 DB에서도 강제한다:** 승인 대기 1인 1개, 두 사람 사이 요청 1개, 승인 1건당 강의실 1개.
- **비밀번호:** scrypt 해시로만 저장한다.
- **실시간 갱신:** 채팅 2초, 알림 5초 polling.

## 로컬 실행

```bash
npm install
cp .env.example .env.local   # 값 채우기
npm run dev                  # http://localhost:3000
```

1. Supabase SQL Editor에서 `supabase/schema.sql` 전체를 실행한다. 이전 버전 DB라면 `migration_m4.sql`, `migration_m5.sql`을 차례로 실행한다.
2. 시드 15명을 넣는다: `POST /api/admin/seed` (헤더 `x-demo-secret: <DEMO_ACCESS_SECRET>`)
3. 테스트: `node scripts/tests/account-test.mjs`, `node scripts/tests/flow-test.mjs <DEMO_ACCESS_SECRET>`

## 시연

- `/demo`: 비밀코드를 입력하면 가상 시드 계정으로 로그인한다. 추천 카드의 QR을 휴대폰 B로 찍어도 된다.
- 강의실 메뉴 "⏩ 3일 뒤로 이동 (시연용)"으로 수강 기간을 바로 끝낼 수 있다.
- `/demo` 아래 "시연 데이터 초기화"는 시드 15명만 남기고 모두 지운다.
