# 교양필수 ♥

> "우리 사이엔 무슨 일이 생길까?"
> AI가 수강생을 분석해 다른 전공 학생과 이어주는 대학 생활 웹
> 바이브코딩 대회 출품작 · 주제 "AI로 다시 쓰는 대학생활"

## 문제

1학년 때는 과대가 과팅을 잡아주지만, 2학년부터는 지인을 통하지 않으면 다른 과 사람을 만날 계기가 없어요.

## 해결

1. **학적 등록:** 전공과 '전공 밖의 나'(특징 키워드, 음악 취향)를 버튼으로 고른다.
2. **AI 학사 분석:** AI가 전공과 성향의 조합을 해석해 학생증에 보여준다.
3. **AI 추천 수강 목록:** AI가 다른 전공 학생 3명을 고르고 추천 근거를 보여준다. 근거는 전공 시너지, 성향의 보완 관계, 실제 공통점이다.
4. **수강신청 → 수강 승인:** 친구 요청을 보내고, 상대가 승인하면 강의실(채팅)이 열린다.
5. **우리의 강의계획서:** 실제 개설 교양(2026-2학기, 319개 분반)을 바탕으로 AI가 두 사람만의 첫 만남 계획을 만든다. *(개발 중)*

## AI가 하는 일

| 단계 | 코드 | AI (Claude) | 서버 검증 |
|---|---|---|---|
| 학사 분석 | 입력 정리 | 전공×성향 해석 | 스키마 검증, 실패 시 1회 재시도 후 기본 분석 |
| 매칭 | 본인·같은 과·관계 있는 사람 제외, 최대 20명 | 상위 3명과 근거 선정 | 후보 ID 실존, 근거 키워드가 두 프로필에 실제로 있는지 검사 → 1회 재시도 → 규칙 기반 추천 |
| 강의계획서 | 과목 후보 최대 20개 추림 | 1개 선택과 재해석 | 과목 ID 검증. 과목명·교수·시간·장소는 원본 그대로 |

- 사용자 입력은 데이터로만 다루고, 그 안의 지시문은 따르지 않아요.
- MBTI와 혈액형은 판단 근거로 쓰지 않고, 궁합 점수도 보여주지 않아요.

## 기술 스택

Next.js 16 (App Router) · TypeScript · Tailwind CSS 4 · Supabase (Postgres) · Anthropic Claude API (`claude-sonnet-5-5`)

- 휴대폰 브라우저로 접속하는 모바일 우선 웹이에요. PC에서는 사이드바 레이아웃으로 바뀌어요.
- 클라이언트는 Supabase에 직접 접근하지 않고 Next.js API만 호출해요. 모든 테이블에 RLS를 켜 두었어요.
- 수강신청 규칙은 DB에서도 강제해요. 승인 대기 요청은 1인당 1개, 같은 두 사람 사이의 요청은 방향과 상관없이 1개만 가능해요.
- 채팅은 2초, 알림은 5초 간격으로 확인해요. 읽음 표시 "1"이 있어요.

## 실행 방법

```bash
npm install
cp .env.example .env.local   # 값 채우기
npm run dev
```

1. Supabase SQL Editor에서 `supabase/schema.sql`을 실행한다.
2. 시드 15명을 넣는다: `POST /api/admin/seed` (헤더 `x-demo-secret: <DEMO_ACCESS_SECRET>`)
3. 데이터를 다시 변환할 때는 `npm run convert:departments`, `npm run convert:courses`를 실행한다.
